## 4. デモ（`index.html`）の構成 ― 「デモhtml全ページ分」

単一ファイルのSPA（タブで画面切替）。以下を網羅：

| 画面 | 内容 |
| --- | --- |
| ホーム（経営DB） | 当月売上/入金/未入金/商談件数・月次売上推移（2-1月）・フェーズ別ドーナツ・未入金60日アラート・今月受注予定・**出荷予定リスト**・サンプル送付月次・最近の活動 |
| リード 一覧/詳細 | 流入経路・サンプル送付済＋送付日・取引先変換ボタン |
| 取引先 一覧/詳細 | 配送先住所×3・請求書送付先・取引履歴・未入金額・関連（商談/活動/請求書） |
| 商談 一覧/詳細 | フェーズPath・明細・送料・値引・**出荷情報（予定/実績・着日）**・入金情報・関連帳票（見積v1/v2＋自動生成3帳票） |
| 商談 新規作成モーダル | 商品選択・数量・単価・送料・値引・備考 |
| 請求書 一覧/詳細 | 振込先2口座・入金済にする |
| 振込先口座マスタ ＋ 追加モーダル | 自社で口座追加・無効化 |
| レポート一覧 | サンプル送付・未入金・売上 等 |
| ダッシュボード一覧 | 経営/事務（営業・マーケはセレクタのみ） |
| 帳票PDFプレビュー×4 | 見積書・請求書・納品書・出荷指示書（ダウンロード/印刷/メール送付ボタン付き） |

> デモで実装が薄い/未対応の画面 = **営業専用DB・マーケ専用DB**（セレクタのみ）。実Org構築時の要否確認対象。

### デモ操作台本（レクチャー用・問い合わせ→入金消込）
1. リード「大和フードサービス」→「サンプル送付済にする」→「取引先に変換」
2. 取引先「山田農園」→ 配送先×3・未入金¥420,000(70日)・取引履歴を確認 →「新規商談」
3. 新規商談モーダル → 商品/数量/単価/送料/値引/備考 →「保存して見積書を出力」→ 見積PDF（有効期限=発行+1ヶ月）
4. 商談詳細 →「受注（100%）にする」→ **請求書・納品書・出荷指示書の3帳票が自動生成** → 請求書へ
5. 請求書PDF → インボイス番号・振込先2口座・角印を確認
6. 「入金済にする」→ 入金日入力運用を説明
7. ダッシュボード（経営・事務の未入金60日赤表示）

> ⚠️ デモの「自動生成」「60日アラート」は見せかけ挙動。実Orgで同じ動きをするか事前に1周ライブ確認すること。
