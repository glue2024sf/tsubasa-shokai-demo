## 2. デモ手順（問い合わせ→見積→受注→請求→入金消込）

モック公開URL: https://skurashima-cyber.github.io/tsubasa-shokai-mockup/
（本番は実Orgで同フローを実演。以下はモックの操作順＝レクチャー台本）

1. **リード（問い合わせ）**: 「リード」タブ → 大和フードサービス → 「サンプル送付済にする」→「取引先に変換」
   - 訴求点: FAX-DM/Meta広告の流入経路、サンプル送付チェックで重複送付防止
2. **取引先**: 山田農園 → 配送先住所×3・未入金¥420,000(70日)・取引履歴を確認 →「新規商談」
3. **商談作成（見積）**: 新規商談モーダル → 商品選択・数量・単価・送料・値引・備考 →「保存して見積書を出力」
   - → 見積書PDF（有効期限=発行1ヶ月）が出る。ボタン1つ出力を訴求
4. **受注確定**: 商談詳細 →（必要なら出荷指示書PDF確認）→「受注（100%）にする」
   - → 請求書・納品書・出荷指示書の**3帳票が自動生成**（見積を踏襲）→ 請求書詳細へ遷移
5. **請求**: 請求書PDF出力 → インボイス番号・**振込先2口座**・角印を確認
6. **入金消込**:「入金済にする」→ 入金日入力運用を説明
7. **ダッシュボード**: 経営層（月次売上・前年同月比・出荷予定リスト）／事務（未入金60日超を赤表示）／レポート一覧

> デモ中の注意: 上記5・6の自動生成と60日アラートは**モックの見せかけ挙動**。実Orgで同じ動きをするか事前に1周ライブ確認しておく。
